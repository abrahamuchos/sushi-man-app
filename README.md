# Sushi Man 🍣

A Flutter practice project for a Sushi restaurant application. This project was developed to explore UI/UX patterns, state management, and navigation in Flutter.

It is made solely for educational purposes.


<img src="/docs/screenshots/get-started.png" width="200px" alt="get-started">

## ✅ Features

- **Sushi Menu:** Browse a diverse catalog of sushi rolls and Japanese dishes.
- **Detailed View:** Access specific information, ingredients, and descriptions for each item.
- **Cart System:** Add your favorite sushi to the cart and manage your order.
- **Responsive Design:** Clean and modern interface tailored for a premium food experience.

## ⚙️ Tech Stack

- **Flutter:** 3.6.0
- **Dart:** Latest stable version
- 

## 💾 Installation

Install and run

1. Clone and move to folder
```bash
$ git clone git@github.com:abrahamuchos/sushi-man-app.git
$ cd sushi-man-app
```

2. Install dependencies
```bash
$  flutter pub get
```

3. Run dev `flutter run`

If you encounter issues, run `flutter doctor` to check for missing dependencies or configuration errors.
